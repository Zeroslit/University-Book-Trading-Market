## 命名与分层约定
- 文件名小写中划线；模块内固定为 `*.routes.js` / `*.service.js` / `*.repository.js`。
- repository 只写 SQL，service 承载业务规则，routes 只做校验与编排。
- 统一具名导出（Vue 组件除外）。
- 中文注释用于说明业务规则来源，例如「需求 6：发货后 7 天未确认自动确认收货」。
