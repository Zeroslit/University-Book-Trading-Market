# 05 接口清单

## 0. 约定
- 基址：`/api/v1`。请求/响应均为 JSON（图片上传为 `multipart/form-data`）。
- 鉴权：`Authorization: Bearer <accessToken>`。角色列含义：`公开`=无需登录，`学生`=已登录学生，`校管`=本校管理员，`客服`=人工客服，`平台`=平台管理员。
- 统一响应：`{ "code": 0, "message": "ok", "data": {...}, "requestId": "..." }`；失败时 `code` 为业务错误码（见 `lib/errors.js`）。
- 分页参数：`page`（默认 1）、`pageSize`（默认 20，最大 100）；返回 `{ list, page, pageSize, total }`。
- 幂等：下单、支付、提现、退款等资金接口需带 `Idempotency-Key` 请求头。

## 1. 认证与账号（auth / users / verifications / payment-accounts）

| 方法 | 路径 | 角色 | 说明 |
| --- | --- | --- | --- |
| POST | `/auth/sms/send` | 公开 | 发送短信验证码（场景：register/login/reset/bind/unbind），Redis 限流 |
| POST | `/auth/register` | 公开 | 注册：学校 + 学号 + 手机号验证码 + 密码；返回 token 与认证状态 |
| POST | `/auth/login` | 公开 | 手机号 + 密码登录 |
| POST | `/auth/login/wechat` | 公开 | 微信一键登录（模拟 code 换 openid） |
| POST | `/auth/refresh` | 公开 | 刷新 accessToken |
| POST | `/auth/logout` | 学生 | 登出（jti 入黑名单） |
| GET | `/auth/me` | 学生 | 当前用户 + 学校 + 认证状态 + 权限开关 |
| GET | `/users/me/profile` | 学生 | 个人资料（脱敏） |
| PATCH | `/users/me/profile` | 学生 | 修改昵称/头像/简介（简介过违禁词检测） |
| GET | `/users/me/credit` | 学生 | 信誉分、档位、当前权限限制 |
| GET | `/users/me/credit/logs` | 学生 | 信誉分明细流水 |
| GET | `/users/:id/public` | 学生 | 他人公开资料：昵称、信誉分档位、历史成交量、认证标识 |
| POST | `/verifications` | 学生 | 提交学生认证（学生证图片 URL / 校园邮箱） |
| GET | `/verifications/me` | 学生 | 我的认证记录与当前状态 |
| GET | `/verifications` | 校管/平台 | 待审核认证队列（本校） |
| POST | `/verifications/:id/review` | 校管/平台 | 审核通过/驳回（通知 + 留痕） |
| GET | `/payment-accounts` | 学生 | 我的收款绑定（脱敏列表） |
| POST | `/payment-accounts` | 学生 | 绑定微信/支付宝/银行卡（仅存后四位 + 哈希） |
| POST | `/payment-accounts/:id/unbind/code` | 学生 | 解绑前发短信验证码（二次验证） |
| POST | `/payment-accounts/:id/unbind` | 学生 | 解绑（校验验证码，进入 24h 冷却） |
| POST | `/payment-accounts/:id/default` | 学生 | 设为默认收款方式 |

## 2. 学校与多校（schools）

| 方法 | 路径 | 角色 | 说明 |
| --- | --- | --- | --- |
| GET | `/schools` | 公开 | 按 `keyword/province/city/status` 搜索学校（注册下拉用，禁止手填学校名） |
| GET | `/schools/provinces` | 公开 | 省份 + 城市聚合（级联选择） |
| GET | `/schools/:id` | 公开 | 学校详情与公开配置（论坛版块、是否需认证、跨校开关） |
| POST | `/schools/applications` | 公开 | 申请开通学校 |
| GET | `/schools/applications` | 平台 | 学校开通申请列表 |
| POST | `/schools/applications/:id/review` | 平台 | 审核通过（自动建校 + 生成论坛版块）/驳回 |
| PATCH | `/admin/schools/:id` | 平台 | 学校配置：状态、服务费比例、品类、认证开关、跨校专区 |

## 6. 交易与托管（orders）

| 方法 | 路径 | 角色 | 说明 |
| --- | --- | --- | --- |
| POST | `/orders` | 学生 | 下单（行锁 + 唯一索引防超卖；需 `Idempotency-Key`） |
| GET | `/orders` | 学生 | 我的订单（`role=buyer/seller`、`status`） |

| POST | `/orders/:id/pay` | 买家 | 模拟支付：余额扣款 → 托管冻结（幂等） |
| POST | `/orders/:id/cancel` | 买家 | 未付款取消 |

| POST | `/orders/:id/confirm` | 买家 | 确认收货 → 放款给卖家并扣平台服务费 |
| POST | `/orders/:id/refund-request` | 买家 | 已付款未发货：申请退款 |
| POST | `/orders/:id/refund/agree` | 卖家 | 同意退款（托管款退回买家） |
| POST | `/orders/:id/refund/reject` | 卖家 | 拒绝退款（可转入争议） |
| POST | `/orders/:id/return-request` | 买家 | 已发货：申请退货退款 |
| POST | `/orders/:id/dispute` | 双方 | 发起争议：冻结放款 + 暂停自动确认倒计时 |
| POST | `/orders/:id/arbitrate` | 客服 | 仲裁：强制放款 / 强制退款（写流水 + 通知双方） |
