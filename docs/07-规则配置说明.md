# 07 规则配置说明

所有阈值存 `configs` 表，读取顺序：**学校级配置 → 平台级配置 → 抛错**（不存在硬编码兜底）。
修改通过 `PUT /admin/configs/:key`，带 `version` 乐观锁，并写 `audit_logs`。

## 2. 处罚梯度（`penalty.escalation`，按累计成立次数）

| 累计成立次数 | 处罚动作 | 附加 |
| --- | --- | --- |
| 1–2 | `warning` 站内警告 + 提醒 | 通知本人 |
| 3 | `mute` 禁言 3 天 | 扣 5 分 |
| 4 | `trade_ban` 限制交易 7 天 | 通知 |
| 5 | `login_ban` 封禁 7 天 | 通知 |
| 6–9 | `login_ban` 每次 15 天且逐次加重（6→15,7→20,8→25,9→30） | 通知 |
| 10 | `permanent_ban` 永久封禁 | 申诉入口保留 |
| 严重违规（诈骗/代写代考/涉黄涉赌） | `permanent_ban` 一票永久 | 立即执行 |

计数口径：
- 仅统计 `reports.status = decided` 且 `decision = 成立` 的记录（`penalties` 中 `status != revoked`）。
- 轻度违规 12 个月滚动过期；连续 6 个月无违规可消除 1 次；严重违规永久保留。
- 申诉成功 → 处罚置 `revoked`，信誉分回滚（写一条反向 `credit_logs`，不修改历史记录）。

## 3. 违禁词四级处置（`banned_word.penalty`）

| 级别 | 示例 | 处置 |
| --- | --- | --- |
| L1 提示类 | 手机号、微信号、QQ | 允许发布但打码并提醒 |
| L2 拦截类 | 引流广告、外链、二维码 | 拦截并提示修改 |
| L3 违规类 | 盗版、答案、代写、代考、刷单 | 拦截 + 扣 3 分 + 记违规 1 次 |
| L4 严重类 | 涉黄涉赌涉政、诈骗、辱骂 | 删除内容 + 转人工工单 + 视情节封禁 |

累计升级：同日 L1 提醒 3 次 → 禁言 1 天；L2/L3 累计 3 次 → 禁言 7 天；累计 5 次 → 禁发帖 30 天。
检测覆盖：发帖、评论、私信、个人简介、图片 OCR、AI 客服会话。命中记录写 `word_hits`（含词、位置、处置动作）。
白名单：教材名误伤可通过 `banned_words.scope = school` + `status = whitelist` 例外，或按学校配置白名单词。
