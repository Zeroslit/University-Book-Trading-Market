# 09 真实支付与小程序上线的合规建议

> 本文是二期落地清单。一期所有资金动作均为平台内模拟实现（不接入真实支付、不做真实银行卡鉴权）。

## 1. 接入真实支付的前提条件
1. **主体资质**：需企业主体（个体工商户部分场景受限），开通微信支付商户号与支付宝开放平台账号；教育类交易建议准备办学/校园合作证明。
2. **资金托管合规**：平台“代收代付”本质属于资金归集，需评估是否触及《非银行支付机构条例》。合规路径通常有两类：
   - 使用**持牌支付机构的分账 / 担保交易产品**（如微信支付「服务商 + 分账」、支付宝「资金托管/分账」），平台不实际沉淀资金；
   - 或接入银行存管 / 二类户体系，由银行做资金隔离。
   不要把买家货款长时间沉淀在平台自有对公账户，避免被认定为“二次清算”。
3. **费率与开票**：平台服务费（一期默认 2%，`school.service_fee_bps`）需明确展示、可开票；支付渠道手续费与平台服务费分开记账。
4. **退款合规**：退款必须原路退回，不能退到余额后再提现；一期模拟实现已按“托管款原路退回买家”建模，切换真实通道时映射即可。
5. **提现（代付）**：需开通商家转账到零钱 / 支付宝转账能力，做收款人实名一致性校验、单笔与单日限额、反洗钱名单筛查。

## 2. 代码层面的对接点（适配器已预留）
| 能力 | 一期实现 | 二期对接点 |
| --- | --- | --- |
| 支付 | `escrow.service.mockPay()`：买家余额扣减 + 托管 | `payment.provider = wechat/alipay`；新增 `payments` 表存渠道单号，回调验签后调用同一 `escrow.hold()` |
| 退款 | `escrow.refund()` 直接写流水 | 调渠道退款接口，`pending → success` 异步回调驱动同一流水状态机 |
| 提现 | `withdraw_requests` 落库为 `pending` | 调商家转账接口，`processing/paid` 由回调更新；保留 `reject_reason` |
| 鉴权 | 学号 + 学生证人工审核 | 增加校园邮箱域名白名单校验、学信网/教务系统对接（需学校授权） |
| 短信 | `sms.service` console 驱动 | 阿里云/腾讯云短信（需模板 ID 与签名报备） |
| 图片审核 | 词库前置过滤 + OCR 适配器（默认关闭） | 接入微信 `imgSecCheck` / `mediaCheckAsync` |

## 3. 小程序上线合规要点
1. **主体与类目**：微信小程序需企业主体；服务类目选择「电商平台 / 二手交易」通常需提供《增值电信业务经营许可证》（ICP/EDI）或平台服务协议等材料，以微信最新审核要求为准。
2. **用户协议与隐私**：
   - 《用户服务协议》《隐私政策》《交易规则》《社区公约》四件套必须可访问；
   - 隐私政策需逐项说明收集学号、手机号、收款账号的目的、范围、保存期限（与 `configs.retention` 一致）；
   - 小程序后台需配置「用户隐私保护指引」，收集学号/手机号等敏感信息要单独弹窗授权。
3. **内容安全**：小程序要求接入内容安全检测（`msgSecCheck` / `mediaCheckAsync`）；平台 `banned_words` 词库作为前置过滤，微信内容安全接口作为后置兜底；图片走 `imgSecCheck`，与一期 `ocr_status` 字段对接。
4. **实名与未成年人保护**：涉及资金交易建议接入实名认证；如用户可能为未成年人，需增加监护人同意与消费限制。
5. **交易规则公示**：服务费比例、发货时效、自动确认收货 7 天、争议处理流程、申诉入口必须在显著位置公示（对应 `docs/07` 的配置项，前端动态渲染，避免规则改了文案没改）。
6. **数据合规**：用户数据存放境内；聊天记录与举报证据按 `retention` 到期后清理或匿名化，避免超期保存。

## 4. 上线前检查清单
- [ ] 服务费、SLA、处罚梯度全部来自 `configs`，后台可改且有审计。
- [ ] 资金流水与订单一一对应，可导出对账（`wallet_transactions.order_id` 有索引）。
- [ ] 封禁期间进行中的订单仍可完成或退款（集成测试已覆盖）。
- [ ] 所有处罚都有申诉入口与复审回滚路径。
- [ ] 敏感字段（学号、手机号、收款账号、聊天记录、举报证据）加密 + 脱敏 + 分级授权 + 期限清理。
- [ ] 隐私政策、用户协议、交易规则、社区公约在 Web 与小程序内均可访问。
